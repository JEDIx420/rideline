# RIDELINE Audio Source Directory

This directory is intended for licensed, multi-track uncompressed WAV source audio recordings (e.g., dynamometer steady-state sweeps, onboard microphone stems, exhaust microphones, and intake captures).

## Organization:
```
audio-source/
└── s1000rr/
    ├── original-recordings/
    │   ├── idle_1250.wav
    │   ├── low_4000.wav
    │   ├── mid_8000.wav
    │   ├── high_11500.wav
    │   └── redline_14200.wav
    └── processed-bands/
```

> [!NOTE]
> All raw recording libraries are excluded from public git distribution. Only optimized, properly licensed runtime samples are deployed to `public/assets/audio/`.
